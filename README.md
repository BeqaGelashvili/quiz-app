# Quiz App 🧠

A sleek, responsive trivia web application built using vanilla HTML, CSS, JavaScript, and dynamic JSON data processing. 

## 🚀 Features
- **🌌Modern Dark UI:** Beautifully designed user interface optimized for readability and user engagement.
- **📊Dynamic Category Selection:** Users can choose between multiple topics including Technology, Science, and History.
- **⚙️Custom Quiz Logic:** Pulls from a local or remote JSON database containing 45 questions per subject to generate a 15-question dynamic challenge with custom difficulty selection.
- **📱Fully Responsive:** Clean, grid-based card layout that adapts beautifully across mobile, tablet, and desktop viewports.
